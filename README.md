# Project Infinity | UA
Project Infinity - це мій закритий проєкт, консольна гра, яка є духовним наслідником Elite Dangerous, No Man's Sky та Stellaris. Ця консольна гра поєднує всі ці три гри:
1. Elite Dangerous - його реалістичність та наукову направленість,
2. No Man's Sky - його безмежність та бажання досліджувати,
3. Stellaris - його стратегічність та елементи дипломатії та політи.

Після релізу, я випущу цей проєкт в Open Source тоді кожний зможе зробити свою версію Project Infinity, саме ця назва натякає на безмежність ідей та безкінечність інтузіастів, які візьмутся за проєкт.
Проєкт не вимагає фінансування, він розробляться заради ІДЕЇ.

>Щодо графіки, я обрав псевдографіку, тому-що це простіше та універсальніше. Я не маю досвіду у GameDev, тим баче з графікою. Це Python зі своїми простими бібліотеками.
